# Spring AI Iris Prediction Project

> **Spring AI 기반 붓꽃(Iris) 품종 분류 ML 예측 및 머신러닝 분석 서비스**

---

## 📌 프로젝트 소개
Spring AI 프레임워크와 머신러닝(ML) 데이터 모델을 결합하여, 붓꽃(Iris)의 꽃받침(Sepal)과 꽃잎(Petal) 수치를 기반으로 품종(Setosa, Versicolor, Virginica)을 실시간으로 추론하고 분류하는 AI 웹 서비스입니다.

---

## 🛠️ 주요 기능 & 특징
- **Spring AI ML 추론 모델 연동**: 학습된 Iris 데이터 분류 모델을 통한 실시간 추론 API 구축
- **특징(Feature) 데이터 전처리**: Sepal Length/Width, Petal Length/Width 입력 파라미터 유효성 검증
- **결과 시각화 & 데이터 리포트**: 붓꽃 품종 예측 결과 확률 반환 및 시각화 리포팅

---

## 💻 기술 스택
- **Language**: Java 21
- **Framework**: Spring Boot 3.x, Spring AI
- **AI & Data**: Machine Learning (Iris Classification Dataset)
- **Build**: Maven
